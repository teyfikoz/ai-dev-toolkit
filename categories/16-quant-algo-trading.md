### Quant Volatility Breakout (Polymarket BTC Up/Down 5m)
**Kaynak:** Dan KWPX / Polymarket araştırması (Sep 2026)
**Performans:** +$120,334 PnL / 71 gün (~$1,695/gün), ortalama $350/işlem

**Temel Algoritma:**
```python
# Volatility ratio
V = sigma_short / sigma_long  # V > 1 → agresif hareket

# Fair value estimation (Bayesian update)
def revise_probability(previous_probability, signal_multiplier):
    prior_odds = previous_probability / (1 - previous_probability)
    adjusted_odds = prior_odds * signal_multiplier
    return adjusted_odds / (1 + adjusted_odds)

# Tradable edge
edge = fair_value - avg_entry_price - execution_costs - safety_margin

# Fractional Kelly sizing
def fractional_kelly(win_prob, entry_price, fraction=0.20):
    net_odds = (1 - entry_price) / entry_price
    full_kelly = (net_odds * win_prob - (1-win_prob)) / net_odds
    return max(full_kelly * fraction, 0)
```

**5 Pozisyon Stratejisi:**
1. Dynamic Position Rotation (Up↔Down dinamik dönüşüm)
2. Temporal Arbitrage (Up+Down <$1 iken ayrı zamanlarda al)
3. Hedged Directional (260 Up / 235 Down → 25 net Long)
4. Multi-Market Inventory (BTC 5m + 15m + ETH + SOL aynı anda)
5. Near-Resolution Capture (98.7¢ al → $1'a resolve bekle)

**Kullanım:** Astra için Polymarket signal modülü. Gate 1 (Polymarket observation) için referans.
